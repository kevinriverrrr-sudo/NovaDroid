БЫСТРЫЙ СТАРТ
-------------
1. Распакуйте архив ЦЕЛИКОМ в любую папку (например C:\NovaDroid).
2. Запустите NovaDroidLauncher.exe.
3. Нажмите «Создать инстанс» - мастер проведёт по 5 шагам.
   Образ android-x86_64-9.0-r2.iso подтянется автоматически из images\.
4. На шаге «Интеграция» оставьте включённым «Открыть Android после создания».
5. Дождитесь статуса «Работает» (ADB подключится сам, только localhost).

ВАЖНО
-----
* Виртуализация: включите Intel VT-x / AMD-V (SVM) в BIOS/UEFI и компонент
  Windows «Windows Hypervisor Platform». Без них будет медленный TCG.
* Проверка: Главная -> карточка «Состояние системы» или Настройки -> Диагностика.
* ADB слушает ТОЛЬКО 127.0.0.1 (защита по ТЗ). Наружу не открывается.
* Первый запуск Android в live-режиме ISO: выберите в загрузчике Android-x86
  grub-пункта Live CD. Данные сохраняются на диск instance-NNN\disk.qcow2.
* Образы, скопированные в images\ рядом с лаунчером, подхватываются автоматически.

ВОЗМОЖНОСТИ ВЕРСИИ 0.2 (ЭТАП 2)
-------------------------------
- Мультиинстансы с изоляцией (диск, порт ADB, логи, папки - у каждого свои)
- Параллельный запуск с защитой по RAM (правило 80%) и лимитом одновременно
  работающих инстансов (Настройки, по умолчанию 2)
- Полные и связанные клоны (qcow2 backing files)
- Снимки состояния QCOW2: создание / восстановление / удаление,
  защищённый системный снимок Clean Install, автокопия перед откатом
- Резервные копии с manifest.json и SHA-256, экспорт в .novadroid-backup
  (единый tar-файл) и импорт с проверкой контрольных сумм
- Библиотека APK: SHA-256, метаданные, установка в НЕСКОЛЬКО инстансов
  с таблицей результатов и опциональным снимком перед установкой
- Игровые раскладки клавиатуры: профили, привязка клавиш к касаниям,
  горячая клавиша режима F1, экспорт/импорт JSON. Только ручной ввод -
  БЕЗ макросов, автоогня и обхода игровых ограничений
- Центр производительности: CPU / RAM / диск в реальном времени (60 сек),
  графики и осторожные рекомендации
- Расширенная диагностика: CPU, BIOS-виртуализация, WHPX, Hyper-V,
  GPU-драйвер, OpenGL/Vulkan, конфликты ПО, экспорт отчёта
- Менеджер образов: встроенный каталог Android-x86 с загрузкой и проверкой
- Централизованные логи + отчёты диагностики
