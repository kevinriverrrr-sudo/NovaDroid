# Android-образ (ТЗ 5.5, 5.6)

## Где взять

- **Android-x86** (рекомендуется для MVP): https://www.android-x86.org/download
  Возьмите 64-битный ISO (например, android-x86_64-9.0-r2.iso / Android 9).
- **Bliss OS** — альтернатива: https://blissos.org
- **Собственная сборка AOSP x86_64** — по документации AOSP (этап 2+).

Положите ISO в `%LOCALAPPDATA%\NovaDroid\images\` и укажите его в настройках
инстанса или в «Настройки -> Образ Android по умолчанию».

## Первый запуск (сценарий ТЗ 17)

1. Создайте инстанс с образом ISO, режим загрузки «ISO (live/установка)».
2. Нажмите «Запустить» — QEMU загрузит ISO, появится окно гостя.
3. В гостевом GRUB выберите установку на диск (Install Android-x86).
4. Разметка: используйте весь виртуальный диск (disk.qcow2, 32 GB по умолчанию).
5. После установки выключите гостя, в настройках инстанса переключите
   «Загрузка» на «Диск (установленная ОС)».
6. Теперь инстанс стартует с установленной системой: ADB подключится
   автоматически, версия Android определится сама.

## Проверка целостности (ТЗ 9)

Лаунчер показывает источник, размер файла и его присутствие на диске.
SHA-256 сверяйте со значением с сайта скачивания до помещения образа
в каталог images (инструмент: `certutil -hashfile file.iso SHA256`).

## Чего делать нельзя (ТЗ 10)

- Не добавляйте Google Play / GMS без отдельной лицензии Google.
- Не модифицируйте APK сторонних разработчиков.
- Не используйте образы с предустановленным пиратским ПО.
